# Penkra Logo Variations

## Direction

The first logo pass uses the blue design direction from `TODO.md`:

- Blue Ink: `#073B63`
- Blue Wash: `#B9D8E8`
- Mist/Sky: `#D8EDF6`
- Linen Blue: `#EDF7FB`
- Canvas: `#FFFEFC`

The goal is a calm, trustworthy operations brand, not a loud AI/SaaS mark.

## Variations

1. Folded document + wordmark
   - Best direct signal for paperwork, forms, registrations, and records.
   - Strong candidate for the public website.

2. Rounded P monogram
   - Best candidate for favicon, app icon, and internal control center.
   - More abstract, less paperwork-specific.

3. Conversation + task check
   - Best fit for WhatsApp-first customer experience.
   - Softer and more approachable.

4. Stamp / handled mark
   - Feels official and procedural.
   - Good for invoices, completed work, and document status.

5. Path / logistics mark
   - Broader operational story.
   - Suggests coordination, movement, and follow-through.

6. Editorial wordmark only
   - Most premium and quiet.
   - Would need a separate icon for small app/fav usage.

## Current Recommendation

Start from either:

- `01` if Penkra should immediately read as paperwork/admin help.
- `02` if the brand should feel more expandable and app-ready.
- `03` if WhatsApp-first service should be the dominant first impression.

The strongest combined system may be:

- `02` as the core icon.
- `06` as the refined wordmark.
- Visual language from `01` and `03` inside the website UI mockups.
